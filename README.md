# Mouse Sync Delay

Windows 10/11. Program synchronizuje ręczne kliknięcia z okna lidera do wybranych okien, kolejno, z regulowanym opóźnieniem.

Dodatkowo przycisk **RÓWNO ROZŁÓŻ OKNA** układa zaznaczone okna w równą siatkę na głównym monitorze.

## Build
- GitHub Actions: Actions -> Build Windows EXE -> Run workflow.
- Lokalnie: kliknij `build.bat`.
